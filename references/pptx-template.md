# 从参考 PPTX 生成可复用的 Beamer 模板

适用于「沿用这份 PPTX 的视觉系统」「参考这些页设计论文汇报模板」等请求。输出是可替换文本、公式、图和版式的 LaTeX 模板。只有用户明确选定的内容或素材才进入模板。若只做模板，示例使用占位内容，不要求提供论文。

## 0. 先盘点，再提问

归档本地上传的 `.pptx`。缺文件时，只问用户上传文件；已有可读文件就先盘点，不发通用问卷代替检查。

```sh
python scripts/project_manager.py init "projects/my-template"
python scripts/inspect_pptx.py inspect "projects/my-template" "reference.pptx"
```

读 `template-source/inventory.json`：有画布尺寸、原始顺序（页码从 1 起，含隐藏页）、使用过的版式和母版、候选主题色和字体，以及页面对象。`p5:7` 表示第 5 页的对象 7，`l2:7` / `m1:7` 表示版式 / 母版对象；`:bg` 表示该层自己的背景。用户可用「第 5 页右上角校徽」回答，由助手解析成 ID。对象坐标单位为 bp；组内坐标是相对值。主题值、占位符、对象尺寸和图像关系是线索，不代表最终渲染效果。

优先对照 PowerPoint 导出的 PDF 或代表页截图；可用本地 PowerPoint 或 LibreOffice 渲染时可自行生成对照。如需用户提供 PDF，确认导出是否含隐藏页并建立页码对应。不具备视觉对照时标记「未核验」，可以提出可编辑近似版；只有确实影响选择或用户要求视觉高保真时才补问。候选页只在工作区核对，不把原稿或整页截图带进交付包。默认不推荐隐藏页，只有显式指定才使用。

先简要列出实际看见的页型、候选页与例外，再按以下三轮问。每轮等用户回答后再展开下一轮，用前一轮的选择缩小范围。环境提供结构化提问工具时，有限选项用单选或多选；阶段表和素材列表较长时，允许用编号或自然语言批量答复。没有提问工具就直接在对话中发问题。已明确的答案直接带入表格，不重复询问。

## 1. 整体布局：确定全套规则

把实际观察到的值和页码代入问题。以下页码仅演示提问写法；候选项不存在时不要展示。

| 决策 | 问法与选项设计 | 如何落实 |
| --- | --- | --- |
| 画布 | 「原稿是 4:3。你主要在现有投影上复用，还是改成 16:9？选 **沿用 4:3 / 改 16:9 并重排**。」原稿比例与目标已一致时直接记录。 | 固定输出比例；改比例时重排内容，不拉伸原图。 |
| 全局视觉与优先级 | 「第 1 页用深色标题带，第 4–8 页用白底细标题。正文统一用哪一种？**沿用白底正文（推荐）/ 统一标题带 / 封面和正文各自沿用**。当原位与投影可读性冲突时，优先哪一个？」 | 记录代表页、留白与信息密度、标题位置、主色和正文对比度、字体与替代方案；如选择原位优先，说明仍需视觉复核。 |
| 页眉页脚 | 「第 2–8 页底部是页码和单位名称。模板要 **仅自动页码 / 干净无页脚 / 为单位标识留位置**？封面是否例外？」 | 确定固定区域和显示范围；此处选择保留位置不等于批准使用原 Logo 或单位名称。 |

一轮只问改变输出的 1–3 组选择。原稿存在多个母版时，明确哪个用在正文、哪些仅用在特定页型。若用户想省略细节，同样要给出一个带具体参数的推荐方案让其选择或确认。

## 2. 各阶段怎么设计：选择可复用的页型

先问「模板要按 **论文汇报顺序 / 原稿章节 / 自定义阶段** 提供示例？是否保留封面、过渡页、备份页？」然后按选定阶段提供一张表，每行给出 **建议参考页 → 版式 → 可替换区域**。用代表页说明该阶段为什么适合该版式、没有对应页就明确指出；不要求逐页有原稿映射。同一版式可复用多个阶段，一阶段也可选多个版式。避免把原稿页数当作模板页数。

| 阶段 | 用户需要决定什么（实际提问时引用所见页码） |
| --- | --- |
| 封面／目录（可选） | 「封面沿用第 1 页大标题与署名区，还是用简洁居中封面？目录需要独立页、章节过渡页，还是都省略？」把题目、作者、场合等做成可替换字段。 |
| 主要问题 | 「问题用单栏讲清一个难点，还是左右分栏同时放场景图和失败例子？」 |
| 论文贡献 | 「贡献需要一页要点列表，还是用分栏呈现贡献与对应价值？」 |
| 前置知识 | 「主要放术语对照还是符号和公式？是否同时提供文字页与公式页？」 |
| 论文方案 | 「要 **总览图＋步骤页 / 只有步骤页 / 只要总览图**？步骤页是左文右图，还是上方公式、下方推导或例子？」 |
| 实验 | 「主要是通栏大图，还是双栏对比？需要单独的结果表版型吗？」保留足够空间放坐标与图例。 |
| 总结与讨论 | 「以一段结论和后续工作收尾，还是要一页突出一句结论？要不要独立 Q&A 页？」 |

允许一句话回复「采用推荐表，方案再加公式页，实验用通栏，省略目录」。将未选阶段标为省略，不自动补页。如以后将模板用于完整论文汇报，仍按主 Skill 的内容约束和获准大纲写作。

## 3. 原素材清单：逐项确定哪些进入成品

根据上轮保留的页型，只列有价值的候选。用可识别的名称、源页位置或母版、候选文件／对象 ID、目标页与用途来问；同一原件出现在多页时可合为一项，列出应用范围。尤其区分以下操作：

| 选项 | 模板中会发生什么 |
| --- | --- |
| 按样式重建 | 用 Beamer/TikZ/LaTeX 重建配色、线条、排版或图表结构；正文、图和名字用占位示例。 |
| 复用原件 | 只复制明确选中的对象（如 `m1:8` 校徽），按已选范围放置。说明是原图、指定裁切，还是需要可编辑地转写指定文字/表格。 |
| 用占位或省略 | 对应位置留可替换框，或移除该元素。未确认的原件默认为不复用。 |

可直接问：「有三项值得确认：**A** 第 1 页母版右上角校徽：原图用于封面 / 留标识位 / 省略；**B** 第 5 页流程图：只重建图文结构 / 复用指定原图 / 换占位图；**C** 第 9 页实验图：建议换占位图。是否还有必须保留的原件？」最后收口为可操作答案，如「A 只用于封面，B 参考样式，C 占位」。「都保留」有歧义时，只追问是保留对应位置还是复制清单里的原件。如果没发现值得复用的素材，问一句「示例页都用占位内容，不复制原素材，是否可以？」即可。备注、旧正文、隐藏页、页底署名、链接、动画、视频、嵌入文件等不因选了同一页或母版而自动获得批准。

对于裁切、遮挡、旋转、SVG 带备用位图等情况，说明提取的是完整嵌入图而非 PPTX 中最终可见的像素：如果原图会露出不应出现的内容，改用用户认可的裁图或独立资产。复杂图表、SmartArt、EMF/SVG、渐变和动效可按已选方式重画或请求单独提供 PDF/PNG 等源文件。不要用一张整页截图替代可编辑框架。将助手无法确认或还无法实现的差异列为待选项，不将降级当作用户答案。

## 4. 确认、生成与复核

1. 将三轮答复汇总到 `outline.md`（模板设计单）：参考文件与指纹、整体规则、按顺序排列的阶段／代表页／版型、原件白名单（源对象、用途、作用范围和处理方式）、降级及待定项。将它发给用户；对最终版本的明确确认后才提取和生成。默认方案、选择了「沿用原布局」或沉默都不能推导出原件白名单。若后续变更了用途或想用额外原件，只补问有变化的选项。
2. 只用已确认的 ID 运行 `extract`。无原图则跳过此命令。它只支持从单个对象或背景中提取嵌入的 PNG/JPEG，不抓取链接；保留原始字节并记录对象与哈希。

   ```sh
   python scripts/inspect_pptx.py extract "projects/my-template" --asset p1:4 --asset p8:6
   ```

3. 从确认的设计单建立 `template-spec.json`。下面是最小示例，实际内容按确认项填写，`source_sha256` 从盘点文件复制，页码从 1 起。没有参考页的阶段用空数组。`overall.logo` 会将批准的图放在普通非 `plain` 页的页脚；`frames[].logo` 只显示在指定的 `cover`；`frames[].image` 可用于 `figure` 与 `two-column`；`frames[].background` 铺满指定帧的画布，所以只用于已经核对可拉伸或同宽高比的原件。任一素材字段未指定时不使用原件；提取目录只应包含这里选用的图。可选 `latin_font` 和 `cjk_font` 不指定时使用 TeX Gyre Heros 和 FandolHei。

   ```json
   {
     "source_sha256": "<inventory.json 中的 sha256>",
     "overall": {
       "canvas": "source", "density": "standard", "header": "plain", "footer": "number",
       "colors": {"accent": "315C88", "text": "182231", "background": "FFFFFF", "on_accent": "FFFFFF"}
     },
     "labels": {
       "author": "报告人", "date": "场合与日期", "body": "解释公式中的符号及适用条件。",
       "point": "填写本页要点", "evidence": "填写支撑证据", "figure": "图表占位",
       "caption": "图注：填写对象、指标和条件。", "summary": "概括结论并说明一项可开展的后续工作。"
     },
     "frames": [
       {"stage": "封面", "title": "报告标题", "layout": "cover", "reference_pages": [1]},
       {"stage": "论文方案", "layout": "two-column", "reference_pages": [], "body_heading": "核心步骤"}
     ]
   }
   ```

   `canvas`: `source` / `16:9` / `4:3`；`density`: `roomy` / `standard` / `compact`；`header`: `plain` / `band`；`footer`: `none` / `number`。示例页型：`cover`、`divider`、`bullets`、`two-column`、`figure`、`formula`、`summary`。参考页码用于溯源，不会自动搬运该页。脚本提供基础版型；超出这些选项的已确认布局（如定制标题带、结果表、矢量裁图）应在生成后手工完善，或直接编写同样可独立编译的 `main.tex` 和本地主题。手工落实的原件仍记入设计单和素材清单，仅把最终使用的批准文件放到 `slides/`。

   ```sh
   python scripts/generate_beamer_template.py "projects/my-template" "projects/my-template/template-spec.json"
   python scripts/project_manager.py approve-outline "projects/my-template" --yes
   python scripts/build_pdf.py build "projects/my-template"
   ```

4. 核对 `build/check.json`，逐页检查 `build/pages/`。按设计单验证画布、页眉页脚、示例顺序、字号、图文安全区、字体替代、原件与目标作用范围。以参考渲染核对承诺复刻的细节；无参考渲染时如实报告。检查 `slides/` 内容与白名单一致、所有链接为相对路径、正文和公式可编辑，且移走原 PPTX 后从 `slides/` 仍可编译。模板不包含论文事实时无需运行论文证据检查。
5. 交付 `slides/main.tex`、本地 `.sty`、用到的素材、PDF 预览和确认的设计单；使用脚本时附 `template-spec.json` 便于审阅配置。原始 PPTX 与盘点文件留在 `template-source/`，无需交付。若运行环境不能编译或渲染，列出未验证项与复现命令。
